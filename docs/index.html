DIVIDE
// gemeinsame ausgaben aufteilen — simpel und fair
// FEATURES
  • ▸Mehrere Aktivitäten — Ausflug, Urlaub, WG-Kasse
  • ▸Ausgaben erfassen — wer hat was bezahlt
  • ▸Automatische Schulden-Berechnung mit minimalem Settlement
  • ▸Passwort-geschützt — geteilter Zugang, JWT Session
  • ▸PWA — installierbar auf dem Handy, optimiert für iPhone
  • ▸Self-hosted — deine Daten, dein Server
// INSTALLATION
// ein befehl reicht
curl -fsSL https://raw.githubusercontent.com/haenrick/divide/main/install.sh | bash klicken zum kopieren
Benötigt: Docker — wird automatisch installiert falls nicht vorhanden.
// update cd divide && docker compose pull && docker compose up -d
// WIE ES FUNKTIONIERT
  1. Install-Skript ausführen — Passwort und Port eingeben
  2. Aktivität anlegen — z.B. "Griechenland 2025"
  3. Teilnehmer hinzufügen
  4. Ausgaben eintragen — wer hat was bezahlt
  5. Schulden-Ansicht zeigt: wer zahlt wem wieviel
